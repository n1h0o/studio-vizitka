# Проверка сайта

## Перед передачей

- `pnpm lint`
- `pnpm build`
- Открыть preview в браузере и проверить ширину desktop/tablet/mobile.
- Проверить переходы навигации и мобильное меню мышью и клавиатурой.
- Заполнить контактную форму тестовыми значениями; проверить нативную валидацию и подтверждение «адрес не настроен» без передачи данных.
- Проверить фокус, контраст, горизонтальное переполнение и режим `prefers-reduced-motion`.

## Проверки текущей версии

- Production-сборка Vite + TypeScript: пройдена.
- Oxlint: пройден.
- `pnpm audit --prod`: известных уязвимостей не найдено.
- Ручная браузерная проверка desktop: заголовок, секции, навигация и контактный блок отображаются.
- Мобильная ширина 390px через iframe: в accessibility tree присутствует мобильное меню; раскрытие и переход по якорю проверены. Проверка встраиваемого скриншота для iframe отображала пустой фон, поэтому визуальную оценку mobile-среза делал по DOM/accessibility tree и правилам CSS; прямой desktop preview отрисовался штатно.
- Форма проверена без настроенного адреса: показано честное сообщение, тестовые данные остаются локальными.
- Автоматические функциональные тесты не добавлялись.

## Проверки редизайна ST-002: сайт и портфолио

- `pnpm lint` — пройден.
- `pnpm build` — TypeScript и Vite build пройдены.
- Chromium desktop 1440px: бумажный первый экран, синий градиент заголовка и навигация отрисованы.
- Chromium mobile 390px: первый экран адаптирован; кнопка основного действия помещается в колонку и стрелка видна.
- Ссылка «Портфолио» присутствует в основной навигации и ведёт к `#work`; карточка собственного проекта ведёт к `#top`.

- Секция портфолио имеет отдельную светло-голубую градиентную поверхность перед тёмным разделом принципа работы.
- `pnpm lint`, `pnpm build` и `git diff --check` пройдены после корректировки; автоматические функциональные тесты не добавлялись.
