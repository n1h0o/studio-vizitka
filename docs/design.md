# Дизайн-система: сайт-визитка студии

Статус: reference lock для первой реализации. Дата: 2026-10-24.

## Краткое задание

Дизайним одностраничный сайт программной студии для русскоязычных потенциальных заказчиков. Главная цель — ясно показать направления работы и перевести посетителя к обсуждению проекта. Тон — прямой, предметный, технически уверенный. Ограничения: пока нет подтверждённого названия, контактного адреса, клиентских кейсов и отзывов; не выдумывать их, не собирать личные данные внешнему сервису. Путь: прямой build после фиксации референсов.

## Исследование

Стиль исследован через резервный каталог Refero Styles, так как MCP-поиск Refero вернул `NO_SUBSCRIPTION`.

- [Alejandro Mejias — acid-lit brutalist atelier](https://styles.refero.design/style/5f802b93-5f46-470f-baaf-173737189c9d) — главный источник: монохромные поля, жёсткая сетка, крупные рубленые заголовки, технические моноширинные подписи и один яркий акцент на действиях. Избегаем коммерчески лицензируемого FK Raster; используем системный узкий гротеск с корректными fallback.
- [AI for Business / Dayos — brutalist editorial showroom](https://styles.refero.design/style/ee403055-480e-4bd4-9216-07c9ae2dde2e) — заимствуем нумерацию и крупный типографический масштаб. Не используем их тёплый серый холст и мятный/жёлтый семантические цвета.
- [Dash Digital Studio — editorial museum](https://styles.refero.design/style/6036b661-3886-4f76-a5e6-bb8960eb7db5) — берём свободный галерейный ритм и ясную типографическую иерархию. Не переносим дорогую фотоподачу и реальный портфель на сайт без своих материалов.

## Reference lock

**Основное направление:** архитектурный монохромный сайт цифровой студии с редакционной типографикой и компактными инженерными метками.

**Сохраняем:** графитовую/чёрную основу; резкий белый текст; очень крупные капс-заголовки; прямые края; тонкие линии сетки; аккуратные индексы и подписи моноширинным шрифтом; высокий контраст.

**Заимствуем:** кислотно-зелёный `#D7FF3F` только для главных действий и одного графического маркера; нумерацию разделов и свободный ритм без карточек по умолчанию.

**Токены:**
- `--canvas: #111210` — основной фон;
- `--surface: #F0F0EB` — один светлый контрастный раздел;
- `--ink: #F4F4EF` — основной текст на тёмном фоне;
- `--ink-dark: #161713` — текст на светлом фоне;
- `--muted: #A5A79E` — вторичный текст;
- `--line: rgba(244,244,239,.22)` — разделители;
- `--accent: #D7FF3F` — CTA и активный маркер только;
- display: локально поставляемый Oswald Variable (SIL Open Font License), крупный uppercase с плотным межстрочным интервалом;
- body: Inter Variable (локальная npm-зависимость), 16–18px;
- labels: DM Mono (локальная npm-зависимость), 11–12px, uppercase, увеличенный tracking;
- сетка: max-width 1440px, базовый шаг 8px, горизонтальные отступы адаптивны;
- кнопки: радиус 3px, карточки не использовать без содержательной причины, тени/градиенты не применять.

**Медиа:** собственные кейсы и фотоматериалы не предоставлены. Первый экран строится на типографике и простой чертёжной диаграмме из SVG/CSS; это декоративный кодовый мотив, не симуляция готового продукта.

**Явно отвергаем:** бежевую «редакционность» по шаблону; фиолетовый SaaS-градиент; стоковые портреты и поддельные отзывы/логотипы; фиктивные метрики; карточную сетку «всё обо всём»; сложную декоративную 3D-графику.

## Решения

| Решение | Источник | Правило роли | Причина |
|---|---|---|---|
| Чёрно-белая основа и крупная типографика | Alejandro Mejias | Акцент не расползается на большие поверхности | Подходит студии разработки и отличает подачу без вымышленных фотокейсов |
| Яркий лайм на CTA и маленькой метке | Alejandro Mejias, адаптация | CTA/активное состояние только | Даёт один заметный сигнал действия |
| Крупные индексы и ритм разделов | Dayos + Dash Digital Studio | Индекс вспомогательный, не заменяет содержание | Держит композицию сайта без придуманного портфолио |
| Контентные блоки вместо фальшивого портфолио | Ограничение владельца/факты проекта | Не представлять задумки как выполненные проекты | В папке нет подтверждённых кейсов |
| Разделы услуг и процесс | README/AGENTS проекта | Только реально заявленные направления и описанный рабочий порядок | Показывает предложение и снижает неопределённость клиента |

## Проверка качества

Проверить реальную страницу на широком и мобильном viewport, клавиатурное управление, контраст, reduced motion, отсутствие горизонтального скролла, состояния формы. Сравнить вид с reference lock, не снимать ограничения на акцент и правдивость контента.
