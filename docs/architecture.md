# Архитектура сайта-визитки

## Решение

Статическая одностраничная frontend-программа на React 19, TypeScript и Vite. Backend и база данных не нужны: сайт не хранит данные, не авторизует пользователей и не отправляет форму на сервер.

## Модули

- `src/App.tsx` — содержимое страницы, доступная навигация, мобильное меню и поведение формы.
- `src/App.css` и `src/index.css` — компоненты и адаптивные design tokens.
- `public/fonts/` — локальная гарнитура Oswald Variable с лицензией SIL OFL; Inter Variable и DM Mono поставляются локально пакетами Fontsource. Внешние запросы шрифтов отсутствуют.
- `index.html` — язык страницы, метаданные и точка подключения приложения.
- `VITE_CONTACT_EMAIL` — опциональная клиентская настройка. Когда адрес указан, форма создаёт `mailto:`-черновик на устройстве посетителя. Без адреса форма сообщает, что письмо не отправлено. На сервер введённые поля не передаются.

## Границы и риски

- Контакты владельца отсутствуют; для рабочего приёма заявок нужен настоящий адрес.
- Название студии пока нейтральное и не является утверждённой торговой маркой.
- Фактические клиентские работы не указаны и не показываются.
- `mailto` зависит от настроенной почтовой программы и не подтверждает доставку.
- Размещение/деплой не входит в этот этап. Для Vercel достаточно статической сборки Vite; настройки проверять при отдельном согласованном релизе.
