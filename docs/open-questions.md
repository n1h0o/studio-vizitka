# Открытые вопросы перед публичным запуском

1. Подтвердить название/бренд студии и окончательное написание wordmark.
2. Добавить реальный адрес для заявок (`VITE_CONTACT_EMAIL`) или выбрать серверный приём формы с отдельными требованиями к хранению, приватности и защите от спама.
3. Если это важно для продаж, указать основной регион работы и языки обслуживания.
4. Добавлять будущие продаваемые демо-кейсы в портфолио только после реализации, проверки и подготовки достоверного описания.

Текущая версия сознательно использует нейтральное название, русский язык, не заявляет регион и показывает только собственный готовый сайт студии. Демо-продукты будут создаваться поэтапно из корневого списка README и добавляться как кейсы после готовности.
