# Сайт-визитка студии разработки

Одностраничный сайт на React, TypeScript и Vite. Тексты не содержат придуманных клиентов, кейсов, отзывов или метрик. Название и способы связи вынесены в конфигурацию и добавляются после подтверждения владельца.

## Запуск

```bash
pnpm install
pnpm dev
```

## Проверки

```bash
pnpm lint
pnpm build
```

## Контакты

До заполнения реального адреса форма не отправляет данные. Скопируйте `.env.example` в `.env.local` и задайте `VITE_CONTACT_EMAIL` — тогда отправка откроет письмо в почтовой программе посетителя. Внешний обработчик формы не подключён, данные не уходят на сервер.
