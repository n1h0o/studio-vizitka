# Сайт-визитка студии разработки

Одностраничный сайт на React, TypeScript и Vite. Тексты не содержат придуманных клиентов, кейсов, отзывов или метрик. Название и способы связи вынесены в конфигурацию и добавляются после подтверждения владельца.

## Запуск

```bash
pnpm install
pnpm dev
```

## Проверки

```bash
pnpm lint
pnpm build
```

## Контакты

До заполнения реального адреса форма не отправляет данные. Контактная точка задаётся через локальную конфигурацию; не подключайте внешний обработчик формы без согласования.
